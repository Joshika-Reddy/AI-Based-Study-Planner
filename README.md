📚 AI Study Planner Web App
🚀 Overview

The AI Study Planner is a Flask-based web application that generates personalized study schedules based on subjects, marks, and difficulty level. It uses a weighted algorithm to intelligently distribute study hours and visualizes results using Chart.js.

✨ Features
📊 Personalized study schedule generation
🧠 Smart weighted algorithm (marks + difficulty)
📈 Interactive bar chart visualization (Chart.js)
📝 Dynamic subject input form
⚡ Real-time result generation
🎯 User-friendly UI
🛠️ Tech Stack
Frontend: HTML, CSS, JavaScript, Chart.js
Backend: Python, Flask
Templating: Jinja2
Tools: Git, GitHub
